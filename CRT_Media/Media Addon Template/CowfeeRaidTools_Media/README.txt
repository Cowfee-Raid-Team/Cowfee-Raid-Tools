Cowfee Raid Tools - Media

Your own sound files for Cowfee Raid Tools, in a folder of their own, so updating Cowfee Raid Tools
never removes them.

Set it up once:
1. Copy this whole CowfeeRaidTools_Media folder into Interface\AddOns, next to CowfeeRaidTools
   (so you have Interface\AddOns\CowfeeRaidTools_Media\CowfeeRaidTools_Media.toc).
2. Put your .ogg or .mp3 files in its Sounds folder.
3. List each file's name in Sounds.lua (open it in Notepad; the example there shows how).
4. Restart the game. A /reload may not find files added while the game was running.

Instead of step 3 you can type a file's name on Cowfee Raid Tools' Quality of Life > Sounds tab. That
tab has a Test button for each file, which says whether the game found it.

Files in the old place, Interface\AddOns\CowfeeRaidTools\CRT_Media\Sounds, still play, but updating
the addon removes that folder, so move them here.
