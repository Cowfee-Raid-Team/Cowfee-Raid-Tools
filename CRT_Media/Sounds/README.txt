Your own sounds for Cowfee Raid Tools: the old place.

The new place is the CowfeeRaidTools_Media companion addon. Its template is in the
CRT_Media\Media Addon Template folder inside this addon: copy CowfeeRaidTools_Media from there into
Interface\AddOns once, and keep your files in its Sounds folder. Updating Cowfee Raid Tools replaces
this whole folder, this Sounds folder included, but never touches CowfeeRaidTools_Media.

Files left here still play, and so do files in the older Sounds folder at the top of CowfeeRaidTools.
Type a file's name on the Quality of Life > Sounds tab to list it, and use its Test button to check
the game finds it. A file added while the game is running may need a game restart, not just a /reload.
